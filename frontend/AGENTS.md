# Moby Моя семья — постоянный контекст

Перед работой читать docs/PROJECT_NOTES.md. Исходное продуктовое ТЗ: references/tz/TZ_Moby_Kids_Family_Full_v2.docx; извлечённый полный текст: docs/SPEC-extracted.txt. Визуальные референсы: references/pic (просмотреть все три).

Пользователь поручил связать frontend с backend в корне этого репозитория. Изменять обе части разрешено для этой интеграции. Не подменять прототип утверждением о реальной интеграции с МТБанком: все деньги виртуальные.

React + TypeScript + Vite + CSS + Lucide + fetch. Русский интерфейс, BYN, Moby Coins отдельно от денег. Desktop: родитель слева, ребёнок справа. Mobile: один экран с переключением роли. Проверять 393×852 (iPhone 15 Pro) и 360×800 (Samsung S20 FE CSS viewport), клавиатуру, переполнение и касания от 44px.

Локальное демо хранится в браузере и синхронизирует обе роли. Серверный режим использует backend API, JWT в памяти сессии, реальные UUID сервера, SSE и ключи идемпотентности; не отправлять demo ID в backend и не переключать серверный режим на локальные фиктивные ответы при ошибках. Деньги считать в целых копейках. Никаких реальных банковских операций.

Команды: npm install, npm run dev, npm run check, npm run build, npm run test:e2e. После изменений обновлять docs/PROJECT_NOTES.md, если меняются архитектура или статус интеграции.

Визуальная система: пользователь попросил максимально приблизиться к AI-референсам. Читать docs/design/REFERENCE-DIRECTION.md; тема src/styles/theme/ имеет приоритет над базовым CSS. Использовать глубокий синий #00297C, яркий #0055FF, красные/оранжевые ленты, чёрный текст и белые карточки. Не возвращаться к приглушённой пастельной теме. Отдельные иллюстрации находятся в public/images, промпты и происхождение — docs/design/ASSETS.md.

Структура после рефакторинга: docs/ARCHITECTURE.md. App.tsx — только композиция. Экраны и диалоги — src/features, оболочка телефона — src/components/phone, UI-примитивы — src/components/ui, состояние — src/app и src/hooks, чистая доменная логика — src/domain. Не возвращать монолитные JSX и минифицированные стили. Лимит строки 100 символов, отступ 2 пробела; проверять npm run check:style.
