# Структура frontend после рефакторинга

`src/App.tsx` подключает провайдер семьи и рабочую область. В нём нет экранов, форм и финансовой логики.

| Каталог | Ответственность |
| --- | --- |
| `src/app/` | Общие типы, состояние семьи и состояние каждого телефона |
| `src/hooks/` | Сохранение и обновление семьи, синхронизация вкладок, фокус диалога |
| `src/components/layout/` | Внешняя рабочая область, переключение ролей, рамки устройств |
| `src/components/phone/` | Оболочка телефона, заголовки, навигация, выбор экрана и диалога |
| `src/components/ui/` | Независимые элементы: строки, иконки, поля, прогресс, переключатели, Sheet |
| `src/features/` | Экраны, карточки и формы, сгруппированные по сценариям |
| `src/data/` | Описания уроков и миссий, вопросы, навигация, категории, магазин |
| `src/domain/` | Модель семьи, деньги, ограничения, команды, проверки сохранения |
| `src/lib/` | Клиент backend, звук и совместимый публичный фасад домена |
| `src/styles/` | Базовые стили, тема по референсам и явный порядок их подключения |

## Поток данных

`FamilyProvider` использует `useFamilyStore` и предоставляет состояние обоим телефонам. Команды передаются в чистый доменный `execute`, который создаёт обновлённую копию состояния. Деньги остаются целыми копейками. Сохранение localStorage и обработка браузерных событий остаются в хуке, а не в компонентах.

`PhoneProvider` добавляет роль, текущую вкладку, открытый диалог и выбранный урок. Открытие формы, ошибки и закрытие формы проходят через единый интерфейс. Локальные состояния ответа на урок, QR-результата и загрузки подключения принадлежат соответствующим диалогам и сбрасываются при их размонтировании.

`PhonePage` выбирает экран; `PhoneDialogs` выбирает содержимое модального окна по типизированному реестру. Экран не содержит разметку всех остальных вкладок и всех диалогов.

Команды разделены на платежи, защиту, накопления, задания, награды и социальные сценарии. Общий контекст команды предоставляет проверки денег и проведение платежа. Цены магазина берутся из доменного каталога. API backend по-прежнему изолирован от автономного кошелька и не выполняет его команды.

## Границы компонентов

- Повторяемые сущности имеют собственные компоненты: `ChoreCard`, `TransactionRow`, `LessonNode`.
- Верхние блоки и быстрые действия вынесены из главных экранов. `ChildHome` и `ParentHome` собирают секции, а не дублируют их внутреннюю разметку.
- Каждый диалог расположен рядом со своей функциональностью. Поле денег и оболочка `Sheet` — общие.
- Настройки фокуса принадлежат `useDialogFocus`; расчёт накоплений — `domain/capitalProjection.ts`; звук — `lib/audio.ts`.
- `lib/demo.ts` оставлен фасадом: существующие потребители не зависят от внутреннего размещения доменных файлов.

## Стили

Единственная точка подключения — `src/styles/index.css`. Сначала идут файлы `base/`, затем `theme/`. Порядок исходных правил сохранён: при разделении проверены все 2774 декларации, их селекторы, значения и порядок. Визуальная тема по референсам не заменяется пастельной базой.

## Читаемость

Исходники, тесты и скрипты ограничены 100 символами на строку. Отступ — два пробела, без табуляции и пробелов в конце строки. Проверка закреплена в `scripts/check-style.mjs`, настройки редактора — в `.editorconfig` и `.prettierrc.json`. Сгенерированный `dist` и автономный HTML остаются сборочными артефактами и не подпадают под ограничение строк.

```bash
npm run check:style  # длина строк и пробельные ошибки
npm run check        # стиль, TypeScript, все тесты без браузера
npm run build        # production и автономный HTML
npm run test:e2e     # взаимодействия в браузере
```
